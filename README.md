# ITHelper - инструмент системного администратора

Представляем простой инструмент для системного администратора. Он реализует систему менеджмента устройств в рамках одной или нескольких организаций, которых может насчитываться более 500 штук. В частности, инструмент будет очень полезен при проведении инвентаризации, обнаружении проблемных устройств, поиске свободных и не загруженных устройств для замены в критических расположениях.


# Расположения - Адреса и кабинеты 

Первоначальной вкладкой, которая встречает пользователя при входе в программу является вкладка с расположениями. Адреса, кабинеты, либо иные уникальные расположения - это места, где устройства могут располагаться.

## Древо локаций
На вкладке **Расположения** в левой части экрана расположен список, состоящий из элементов, построенных в формате древа. Начинается всё с **корневого расположения**, домена, в дочерних элементах которого могут располагаться другие элементы древа и их дочерние элементы. Корнем может выступать, например, наименование организации или конкретный корпус.

Над древом располагаются кнопки, позволяющие управлять содержимым. При нажатии на один из элементов у вас появляется функционал для **управления локацией**.
## Управление локацией

Как только вы нажмете ЛКМ по элементу **древа локаций** в оставшейся части экрана у вас будет доступна информация по выбранному расположению. По мимо заданных параметров, там же будет указаны три таблицы-списка с сущностями, имеющими связи с данной: **устройства**, **сотрудники**, **телефоны**. Также присутствует функционал для быстрого добавления связей.

# Устройства и сотрудники

Вкладки **Устройства** и **Сотрудники** схожи по своему функционалу. В верхней части экрана располагаются таблицы, в которых располагаются все объекты из базы данных и их параметры. Над таблицей расположены элементы управления: фильтры и кнопки управления (создание, редактирование, удаление). В самом низу располагается небольшая табличка с параметрами выбранного элемента таблицы.

# Форма ввода данных
В целях более удобного ввода данных была реализована отдельная вкладка, которая позволяет быстро указать все необходимые данные и в случае отсутствия некоторых из них - создать новые объекты. Такой функционал доступен для **Устройств**, **Сотрудников** и **Телефонов**.


# Особенности передачи информации
Функционал программы предоставляет функционал "дистрибуции" данных от одного клиента другому через файлы формата `.ith`, хранящих информации о всех сущностях и связях.
## Замещающий импорт 
Данный тип импорта полностью очистит текущий открытый "проект" и вставит данные из файла.
## Вставочный импорт
Данный тип импорта позволяет добавить недостающие сущности из файла в текущий открытый проект, сохранив все связи. Следует использовать осторожно, поскольку, данный функционал может содержать ошибки.
## Android-приложение
Для более удобного сбора информации в скором будущем будет реализовано Android-приложение.

## Зачем это было реализовано? 
Предполагается, что программа может располагаться IT-отделами в государственных организациях. В программе могут присутствовать данные, которые могут быть отнесены к персональным данным, коммерческой и государственной тайне. Использование ПО в клиент-серверной архитектуре создает дополнительные пути злоумышленникам для получения защищаемой информации. Поэтому, была оставлена возможность исключительно локального размещения на каждом компьютере с передачей информации через файлы.
